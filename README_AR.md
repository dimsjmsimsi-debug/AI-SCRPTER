# Folze AI Studio — دليل التشغيل بالعربي

نسخة أولية لموقع ذكاء اصطناعي متجاوب، بتصميم أسود وأزرق، يتضمن محادثة AI ومناطق Code Studio وSecurity Lab.

## المتطلبات
- Node.js 18 أو أحدث.
- مفتاح API من مزوّد النموذج الذي ستستخدمه.
- اتصال بالإنترنت.

> المفتاح يظل على الخادم داخل ملف `.env`. لا تضعه داخل `public/app.js` أو أي ملف يصل للمتصفح، ولا ترفع `.env` إلى GitHub.

## التشغيل من كمبيوتر أو بيئة تطوير أونلاين
1. فك ضغط المشروع.
2. افتح مجلد المشروع في بيئة تدعم Node.js (مثل بيئة تطوير سحابية موثوقة).
3. انسخ `.env.example` وسمِّ النسخة `.env`.
4. افتح `.env` وأضف مفتاح API في `OPENAI_API_KEY`، وتأكد من اختيار نموذج متاح لحسابك في `OPENAI_MODEL`.
5. في الطرفية شغّل:
   ```bash
   npm install
   npm start
   ```
6. افتح العنوان المحلي الذي يظهر في سجل التشغيل. للنشر العام، استخدم استضافة Node.js وأضف متغيرات البيئة من لوحة الاستضافة، ولا ترفع ملف `.env`.

## التشغيل من هاتف Android
الخيار الأسهل هو استخدام بيئة تطوير سحابية تعمل من متصفح الهاتف وتدعم Node.js:
1. ارفع ملف ZIP إلى بيئة التطوير أو فك ضغطه داخل مساحة المشروع.
2. افتح Terminal إن كانت متوفرة.
3. نفّذ `npm install` ثم `npm start`.
4. استخدم رابط المعاينة الذي توفره بيئة التطوير.
5. للنشر، اتبع تعليمات الاستضافة لإضافة `OPENAI_API_KEY` و`OPENAI_MODEL` كمتغيرات سرية.

إذا كانت البيئة لا تدعم Node.js أو الطرفية، فلن يكفي فتح `index.html` وحده؛ لأن المحادثة تحتاج إلى خادم API.

## الإعدادات
- `OPENAI_API_KEY`: مفتاح API الخاص بك.
- `OPENAI_MODEL`: اسم نموذج متاح لك لدى المزوّد.
- `PORT`: المنفذ (الافتراضي 3000).

## ما تتضمنه النسخة
- واجهة عربية متجاوبة.
- محادثة مع سجل محدود داخل الجلسة.
- مسارات واجهة للمحادثة والبرمجة والمختبر الأمني.
- تحديد معدل الطلبات وحجم الرسالة.
- مفتاح API محفوظ في الخادم وليس في الواجهة.
- معالجة أخطاء API بصورة مختصرة.

## حدود النسخة
- تحتاج مفتاح API صالحاً وقد تُحتسب رسوم بحسب المزوّد والاستخدام.
- Code Studio وSecurity Lab في هذه النسخة أوضاع محادثة موجهة، وليسا محرر تنفيذ أكواد أو ماسح ثغرات آلياً.
- لا توجد قاعدة بيانات أو تسجيل دخول في هذه النسخة؛ لا تنشرها كخدمة عامة مدفوعة قبل إضافة المصادقة، وحصص الاستخدام، والمراقبة، وسياسة الخصوصية.
- لا تشغّل أكواد غير موثوقة على جهازك أو خادمك. اختبر فقط الأنظمة التي تملكها أو لديك تصريح بفحصها.
